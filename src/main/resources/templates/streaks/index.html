Streak Calculation Rules
Meaningful Work Only

Solving DSA problems, completing learning goals, or committing project milestones count as active days.

Single Day Aggregation

Multiple activities recorded within the same day count toward that date without artificial inflation.

Audit-Backed Accuracy

Streaks are never stored as arbitrary counters; they are dynamically derived from actual audit records in MySQL.
